# BRS/BHLS Proposal Context

Este contexto orienta LLMs e agentes sobre a proposta conceitual BRS/BHLS do Paradoxo Mobilidade JP.

## Natureza da proposta

A proposta é um estudo conceitual independente da Paradoxo Labs.

Não é projeto oficial e não deve ser apresentada como decisão pública.

## Status das linhas

As linhas propostas ainda não estão definidas.

Os códigos e trajetos apresentados são sugestões iniciais e precisam ser refinados.

Qualquer agente ou LLM que trabalhe neste eixo deve tratar as linhas como hipóteses, não como rede final.

## Objetivo

Reorganizar a rede de transporte coletivo de João Pessoa com:

- corredores BRS/BHLS;
- terminais;
- estações;
- miniestações;
- alimentadoras;
- interterminais;
- metropolitanas;
- especiais;
- redução da dependência do Centro;
- manutenção da cobertura territorial.

## Princípios

- Não usar BRT clássico como base.
- Priorizar faixas laterais.
- Preservar capilaridade.
- Reduzir radialidade.
- Usar a rede atual como base de validação.
- Integrar bairros, terminais e corredores.
- Criar alternativa orbital pela BR-230.
- Fortalecer conexões Norte-Sul sem passar pelo Centro.
